Fotoarchiv PWA 4.1.0

GitHub Pages hostet die App. Ein kleiner Cloudflare Worker übernimmt nur den sicheren Google-OAuth-Code-Austausch.

1Dateien zu GitHub hochladen

Lege ein GitHub-Repository an, zum Beispiel fotoarchiv, und lade den Inhalt dieses Ordners in das Repository. Danach in Settings → Pages GitHub Pages aus dem Branch main und Ordner / (root) aktivieren.

Danach erhältst du eine Adresse wie https://DEINNAME.github.io/fotoarchiv/.

2Einrichtungs-Assistent öffnen

Wenn GitHub Pages läuft, öffne dort SETUP.html, also zum Beispiel:

https://DEINNAME.github.io/fotoarchiv/SETUP.html

Diese Seite zeigt dir automatisch den richtigen Web-Origin und die richtige Google Redirect-URI.

3Google Cloud einrichten

Aktiviere die Google Drive API und lege einen OAuth-Client vom Typ Webanwendung an. Für diese private Familien-App kann die OAuth-App im Testmodus bleiben; füge die Google-Konten, die sie benutzen sollen, als Testnutzer hinzu.

Client-Secret niemals auf GitHub hochladen. Der Secret kommt ausschließlich in den Cloudflare Worker.

4Cloudflare Worker einrichten

Erstelle einen Worker und kopiere den Inhalt von worker/worker.js hinein. Die benötigten Variablen stehen im Einrichtungs-Assistenten und in worker/README.txt.

Der Worker speichert keine Fotos, Tags oder Tokens. Er tauscht nur den einmaligen Google-Autorisierungscode gegen einen kurzlebigen Zugriffstoken aus.

5Auf dem Tablet installieren

Öffne das Fotoarchiv in Chrome auf dem Android-Tablet, verbinde Google Drive und tippe auf ⬇ App installieren. Danach erscheint Fotoarchiv wie eine normale App auf dem Startbildschirm.

Was liegt wo?

  • GitHub Pages: nur Programmcode der PWA.
  • Google Drive: Originalfotos.
  • Tablet: Tags, Favoriten, Fotoabende und kurzlebiger Zugriffstoken.
  • Cloudflare Worker: nur der Google Client-Secret und der kurzzeitige Code-Austausch.

Bitte beachten

Vor dem Löschen von Browser-/App-Daten immer im Fotoarchiv ⋯ → Katalog sichern verwenden. Sonst können die lokal gepflegten Tags verloren gehen.
