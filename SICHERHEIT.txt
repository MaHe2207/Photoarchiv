FOTOARCHIV PWA 4.1.0 – SICHERHEIT
=================================

GitHub erhält keine Fotos und keine Google-Zugriffstokens.

Google Drive:
- Zugriff nur über drive.readonly
- keine Lösch- oder Schreibfunktion
- Originalbilder bleiben in Google Drive

OAuth:
- Authorization Code + PKCE (S256)
- state-Prüfung gegen CSRF
- Google Client Secret nur im Cloudflare Worker
- kein Client Secret im GitHub-Repository
- kein Refresh-Token im Browser
- Zugriffstoken nur für die aktuelle Sitzung im sessionStorage

Cloudflare Worker:
- speichert keine Fotos
- speichert keine Tags
- speichert keine Tokens
- tauscht nur einen kurzlebigen Autorisierungscode gegen einen Zugriffstoken
- akzeptiert nur den konfigurierten Origin und die konfigurierte Redirect-URI

Tablet:
- Tags, Favoriten, Fotoabende und Cache liegen lokal im PWA-Speicher
- vor dem Löschen von Browser-/App-Daten immer eine Katalogsicherung erstellen

GitHub:
- niemals GOOGLE_CLIENT_SECRET hochladen
- niemals Katalogsicherungen oder private Fotos in das Repository legen
- GitHub-Konto mit Passkey oder Zwei-Faktor-Authentifizierung schützen
