GOOGLE DRIVE – FOTOARCHIV PWA 4.1.0
===================================

Bitte zuerst die veröffentlichte Datei SETUP.html auf GitHub Pages öffnen.
Sie zeigt automatisch die beiden exakten Adressen an, die für Google benötigt werden.

GOOGLE CLOUD
------------
1. Google-Cloud-Projekt anlegen oder auswählen.
2. Google Drive API aktivieren.
3. OAuth-Zustimmungsbildschirm einrichten.
4. Für eine private Familiennutzung kann die App im Testmodus bleiben.
   Die Google-Konten der Nutzer dann als Testnutzer hinzufügen.
5. OAuth-Client erstellen: Typ "Webanwendung".
6. Autorisierte JavaScript-Quelle: den Web-Origin aus SETUP.html eintragen.
7. Autorisierte Weiterleitungs-URI: die Redirect-URI aus SETUP.html eintragen.
8. Client-ID und Client-Secret notieren.

CLOUDFLARE WORKER
-----------------
1. Einen neuen Cloudflare Worker anlegen.
2. Den Inhalt von worker/worker.js als Worker-Code verwenden.
3. Folgende normale Variablen setzen:
   GOOGLE_CLIENT_ID      = Google Client-ID
   ALLOWED_ORIGIN        = Web-Origin aus SETUP.html
   ALLOWED_REDIRECT_URI  = Redirect-URI aus SETUP.html
4. GOOGLE_CLIENT_SECRET als SECRET setzen.
5. Worker deployen und seine workers.dev-Adresse kopieren.

PWA
---
1. SETUP.html auf dem Android-Tablet öffnen.
2. Google Client-ID eintragen.
3. workers.dev-Adresse des OAuth-Brokers eintragen.
4. "Auf diesem Gerät speichern" wählen.
5. Fotoarchiv öffnen und Google Drive verbinden.

SICHERHEIT
----------
- Der Client-Secret darf niemals in GitHub oder die PWA geschrieben werden.
- Die PWA verwendet Authorization Code + PKCE (S256).
- Der Zugriff ist auf drive.readonly beschränkt.
- Der Worker speichert keine Fotos, Tags oder Tokens.
- Im Browser wird kein Refresh-Token gespeichert.
